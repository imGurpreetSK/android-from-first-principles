# Text is CC BY-SA 4.0, not CC BY-NC-SA

Outside contributors can write whole chapters. The repo has no contributor agreement. So each contributor keeps the copyright on their chapter. The maintainer gets only the license that the repo grants. Under CC BY-NC-SA, a contributed chapter could not go into a future book, course or sponsored edition without written permission from its contributor. We chose CC BY-SA 4.0 for all text, so that commercial use is open to everyone, the maintainer included. Code in `samples/` stays MIT.

## Considered options

- **CC BY-NC-SA, no agreement:** others cannot sell the content. But the maintainer can never use contributed chapters for commercial purposes either.
- **CC BY-NC-SA plus a relicense grant in `CONTRIBUTING.md`:** others can use the content only for non-commercial purposes. But each contribution needs an extra legal step.
- **CC BY-SA (chosen):** no agreement is necessary. Commercial use stays open.

## Consequences

- Anyone can republish or sell the text, if they credit it and share it under the same license.
- The decision is hard to reverse. After the maintainer merges contributed chapters under BY-SA, a change to a non-commercial license needs the consent of each contributor.
- The code in `site/` also uses CC BY-SA 4.0 (maintainer decision, 2026-11-14). But Creative Commons recommends against its licenses for software ([Creative Commons FAQ](https://creativecommons.org/faq/)).
